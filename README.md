# Environmental Air Quality Monitoring and Visualization System

An environmental monitoring application developed in LabVIEW with a custom C# GMap.NET control for visualizing real-time air quality data from the OpenAQ API.

## Features

- Interactive map using GMap.NET
- Display air quality monitoring stations
- Search locations by name
- View station information
- OpenAQ API integration
- API key validation
- Download environmental data
- Plot sensor measurements
- Graph visualization
- LabVIEW and C# integration

## Technologies

- LabVIEW 2024
- C#
- .NET Framework
- GMap.NET
- OpenAQ API
- JSON

## Project Structure

```
EnvironmentalMonitoringSystem/
├── GMapControl/

├── graph_data.vi
├── API_Key.vi
└── ...
```

## Getting Started

1. Clone the repository.
2. Open the LabVIEW project.
3. Build the GMap.NET C# control.
4. Obtain an OpenAQ API key.
5. Run `main.vi`.
